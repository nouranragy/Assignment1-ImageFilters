Instructor: Dr. Mohammad El-Ramly

 -------------------------------------------------------------------------------------------------
Program Description: 
-------------------

- This project is a baby photoshop that allows users to apply different filters to images.

- The Program support 16 filters and 2 bonus filters.

   ---------------------------------------------------------------------------------------------
 Tools Versions:
 -
 - IDE: Qt Creator 20.0.2

 - Compiler: MinGW 64-bit

 -  Build System: CMake

   ----
 How To Set Up And Run
 --
- For VS Code : Open the file.cpp and run code.
- For GUI :
  1. Open Qt Creator 20.0.2.
  2. Go To File > Open File or Project.
  3. Navigate To the project folder and select the main CMake configuration file (CMakeLists.txt).
  4. Configure your project kit when prompted (ensure you select Qt 6.12.0 with the MinGW 64-bit kit).
  5. Click the "Configure Project " button.
  6. Once the configuration is complete, simply click the "Run" button to build and execute the application immediately.
